# 偏差说明

## 1. 与设计文档的偏差
- 设计文档中的 Qwen 推理模块当前以启发式本地推理器代替，目的是先打通前后端链路和测试闭环。
- 文档预处理当前支持 TXT 与基础 PDF 文本抽取，OCR 与复杂表格恢复保留为下一轮增强项。
- 结果持久化当前采用本地 JSON/CSV 文件，未接入 PostgreSQL 或 Redis。

## 2. 偏差原因
- 当前阶段优先完成可运行 MVP 骨架与交付资产
- 真实模型密钥、OCR 运行环境和竞赛样本尚未统一接入

## 3. 后续补偿计划
- 接入真实 Qwen API 客户端
- 引入复杂 PDF 与 OCR 预处理能力
- 将启发式召回/推理替换为正式竞赛链路实现
