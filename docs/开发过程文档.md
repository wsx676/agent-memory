# 开发过程文档

## 1. 开发目标
围绕 MVP 设计文档，搭建一套可运行的金融长文档阅读理解系统原型，覆盖前端控制台、后端 API、质量门禁与交付文档。

## 2. 开发顺序
1. 生成 PRD 与技术架构文档
2. 初始化 React 工程与 Git 仓库
3. 设计 FastAPI 服务骨架与数据模型
4. 实现文档导入、预处理、任务执行和结果展示
5. 补充测试、CI、部署手册和交付文档

## 3. 当前实现范围
- 前端 6 个页面路由
- 后端 8 个核心 API
- 文件级数据持久化
- 基础规则检索与启发式推理
- 结果治理与交付物入口

## 4. 质量保障动作
- 前端引入 ESLint、Prettier、TypeScript、Vitest
- 后端引入 pytest、Ruff、mypy
- GitHub Actions 建立前后端双作业 CI

## 5. 下一阶段重点
- 接入真实模型推理
- 增强 PDF/OCR 结构恢复
- 完善补检索与记忆压缩逻辑
- 增强交付打包与预部署脚本
